行程总览

11.05周四抵达日：洛杉矶机场落地 → 好莱坞酒店入住
行程安排
  • 夜间落地洛杉矶国际机场后，直接前往好莱坞区域酒店办理入住，简单休整倒时差，不用再更换住宿，方便第二天直接游玩。
交通接驳
  • 坐 LAX FlyAway 好莱坞专线巴士：24 小时运营，每 30 分钟一班，8 美元/人，直达好莱坞核心区终点站，全程约 40 分钟，下车后步行 5-10 分钟即可到酒店，无需换乘。
住宿选择
奥尼克斯好莱坞酒店：约480元/晚，步行3分钟到 LAX FlyAway 巴士终点站、3分钟到地铁站，含免费早餐，周边有24小时超市、餐厅，半夜落地也能买到食物，后续玩好莱坞所有景点都可以步行到达，不用搬运行李。
💰 费用参考（单人）：交通 60元 + 住宿 400元
💡 注意：落地后直接在机场买一张交通卡（TAP卡），7美元工本费，可充值用于后续地铁、公交出行，不用每次单独买票。
11.06周五正式行程第1天：好莱坞全天游玩
行程细节
  • 上午睡个懒觉倒时差，10点出门步行逛好莱坞星光大道：打卡心仪明星的手印星星地标、TCL中国剧院、杜比剧院（奥斯卡颁奖地），顺路逛好莱坞博物馆（门票约18美元/人），了解好莱坞百年影视发展史。
  • 下午坐地铁1站到格里菲斯天文台：免费开放，是远眺好莱坞山白色标志、俯瞰洛杉矶全城全景的最佳点位，馆内还可以免费参观天文展览、体验天体模拟，傍晚看落日和城市灯光依次亮起，景观极佳。
  • 晚上返回星光大道，在日落大道旁的美式餐厅吃特色汉堡、烤肋排，体验洛杉矶本地夜生活。
交通方式
  • 所有景点集中在3公里范围内，步行+地铁即可，不需要打车。
住宿选择
同上一天（奥尼克斯好莱坞酒店）
💰 费用参考（单人）：门票 130元 + 餐饮 200元 + 交通 10元 + 住宿 400元 = 750元
💡 注意：星光大道上有扮成漫威、迪士尼角色的人主动合照，拍完会索要10-20美元小费，不想花钱直接摆手拒绝即可。
11.07周六正式行程第2天：好莱坞 → 约书亚树国家公园 → 金曼小镇约 2.5h + 2h
行程细节
  • 早上吃完早餐，步行5-10分钟到好莱坞市区的租车点取车（赫兹、安飞士等主流租车公司在好莱坞核心区都有门店，营业点就在星光大道旁，8点即可取车，提前线上预订），向东行驶2.5小时抵达约书亚树国家公园，入园后先到游客中心领取免费徒步地图，咨询当日徒步路线开放情况。
  • 核心游玩点：
    • 隐谷环线（Hidden Valley）：1.6公里轻松徒步，几乎无爬升，看巨型卵石群和密集约书亚树林，是公园标志性打卡点。
    • 骷髅岩（Skull Rock）：天然形成的骷髅造型岩石，旁边有免费停车场，下车即可拍照。
    • 钥匙观景点（Keys View）：俯瞰莫哈韦荒漠和远处的圣哈辛托山，视野开阔，适合拍戈壁全景。
  • 下午4点出园，继续向东行驶2小时，抵达66号公路重镇金曼，逛免费开放的66号公路博物馆，看复古老爷车、老公路路标，体验复古公路文化。
交通方式
  • 优先租普通SUV，约350元/天（含基础保险，适合走荒漠非铺装路段）；约书亚树国家公园门票35美元/车，7天有效，园内可自驾直达所有景点。
住宿选择
欢朋酒店金曼66号公路店
💰 费用参考（单人）：租车+油费+门票 280元 + 住宿 450元 + 餐饮 180元 = 830元
💡 注意：公园内无餐饮补给，出发前提前买好2L以上饮用水、能量棒等便携食物，荒漠紫外线极强，穿长袖、戴帽子墨镜，避免晒伤。
11.08周日正式行程第3天：金曼 → 66号公路小镇群 → 图萨扬320 km / 约 3.5h
行程细节
  • 早上9点从金曼出发，沿66号公路旧道向东行驶，依次打卡经典公路小镇：
    • 塞利格曼小镇：《汽车总动员》原型小镇，整条街布满复古霓虹灯、老爷车、公路主题商店，所有建筑都是动画里的同款风格，适合拍照，中午在当地老牌复古汉堡店吃美式简餐，人均约15美元。
    • 威廉姆斯小镇：66号公路与大峡谷的交汇节点，逛百年复古火车站（每天有复古蒸汽火车开往大峡谷，可选体验）、公路纪念品店，冰箱贴、钥匙扣等伴手礼价格比大峡谷、拉斯维加斯便宜30%左右，可提前采购。
  • 下午3点继续向北行驶1小时，抵达大峡谷南门附近的图萨扬小镇入住，为第二天逛大峡谷做准备，避免当日早起赶路。
交通方式
  • 自驾全程约320公里，车程约3.5小时，沿途小镇主路旁都有免费公共停车场，不用找车位。
住宿选择
威莱斯贝斯特韦斯特酒店：约700元/晚，距离大峡谷国家公园南门仅10分钟车程，含免费早餐，是周边性价比最高的连锁酒店，超市、餐厅配套齐全。
💰 费用参考（单人）：租车+油费 200元 + 住宿 350元 + 餐饮 200元 = 750元
💡 注意：66号公路旧道部分路段没有信号，提前下载好离线地图，不要跟着实时导航走，避免错过景点。
11.09周一正式行程第4天：大峡谷南缘 → 马蹄湾 → 佩吉小镇220 km / 约 3h
行程细节
  • 早上7点出发，10分钟抵达大峡谷国家公园南缘，门票35美元/车，7天有效，入园后直接坐园区免费红线接驳车（核心区不可自驾），按顺序游玩：
    • 马瑟点（Mather Point）：大峡谷官方首推观景台，人少景宽，看峡谷日出和层叠的红色岩壁全景。
    • 布莱特天使步道浅段（Bright Angel Trail）：徒步1-2公里即可下到峡谷边缘，近距离触摸20亿年地质层，不用走完全程。
    • 隐士之路终点（Hermits Rest）：沿线停靠6个观景台，最后一站可以远眺科罗拉多河穿谷而过的景观。
  • 中午12点出园，向东行驶2小时抵达马蹄湾，景点免费开放，徒步1.2公里（平缓沙路）到观景台，俯瞰U形河道环绕红色岩壁的震撼景观，正午到下午3点阳光最佳，拍照无阴影。
  • 傍晚入住佩吉小镇，体力充足可以提前预约次日上羚羊谷参团（可选，约400元/人，需要当地导游带领进入）。
交通方式
  • 自驾全程约220公里，车程约3小时，大峡谷内接驳车免费，不需要额外付费。
住宿选择
佩吉万豪酒店：约880元/晚，距离马蹄湾仅10分钟车程，含免费早餐，周边有大型超市，可补给锡安徒步的食物和水。
💰 费用参考（单人，不含羚羊谷）：租车+油费+门票 180元 + 住宿 440元 + 餐饮 200元 = 830元
💡 注意：马蹄湾观景台无护栏，拍照时不要后退，风大的时候站稳，避免失足；大峡谷内温度比市区高5-8℃，带够水，不要正午长时间徒步。
11.10周二正式行程第5天：佩吉 → 锡安国家公园 → 斯普林代尔小镇190 km / 约 2.5h
行程细节
  • 早上8点出发，向北行驶2.5小时抵达锡安国家公园，门票35美元/车，7天有效，入园后停在游客中心停车场，坐园区免费接驳车前往徒步点，根据体力选路线：
    • 轻松友好版：翡翠池步道（往返3公里，低爬升），沿途看三层瀑布、绿松石色高山湖泊，老人小孩都能走；搭配维琴河步道（往返3.5公里，平路），沿峡谷溪流徒步，岸边都是红色岩壁，出片率高。
    • 体力挑战版：天使降临点徒步（往返8公里，中等难度），锡安标志性景观，登顶可以俯瞰整个锡安峡谷全貌，需要带登山杖，穿防滑鞋。
  • 下午5点出园，入住公园门口的斯普林代尔小镇，吃当地特色墨西哥餐。
交通方式
  • 自驾全程约190公里，车程约2.5小时，锡安核心区只能坐免费接驳车，私家车不能进入。
住宿选择
锡安国家公园卡纳巴：约615元/晚，距离公园入口仅1公里，提供免费接驳车往返园区，含早餐，周边餐厅、户外店齐全。
💰 费用参考（单人）：租车+油费+门票 220元 + 住宿 310元 + 餐饮 200元 = 720元
💡 注意：锡安园区内补给点少，每人至少带2L饮用水；部分徒步路段有浅涉水点，穿防滑防水的徒步鞋，不要光脚踩水，水下石头很滑。
11.11周三正式行程第6天：斯普林代尔 → 拉斯维加斯 → 返程/休闲260 km / 约 2.5h
行程细节
  • 早上9点出发，向西行驶2.5小时抵达拉斯维加斯，办理入住后自由活动，两种方案可选：
    • 休闲体验党：逛拉斯维加斯大道特色酒店，免费看百乐宫音乐喷泉（每15分钟一场）、威尼斯人室内运河、海市蜃楼火山喷发秀，傍晚可以登巴黎酒店埃菲尔铁塔（门票约20美元/人）看城市全景，晚上按需选择看秀（推荐蓝人秀/大卫·科波菲尔魔术秀，提前订票约300-800元/人）。
    • 购物扫货党：前往拉斯维加斯北奥特莱斯，品牌齐全，轻奢、运动、户外品牌折扣普遍为国内3-5折，适合采购服饰、伴手礼。
  • 如果是当日夜间返程航班，下午可以提前还车，坐机场接驳车前往拉斯维加斯麦卡伦机场；如果是次日返程，当晚可以继续体验赌城夜生活。
交通方式
  • 自驾全程约260公里，车程约2.5小时；市区内可以坐免费轻轨，各酒店之间有连通步行通道，不需要打车。
住宿选择（次日返程可选）
拉斯维加斯埃利斯岛酒店：约565元/晚，位于拉斯维加斯大道南端，自带免费室内游乐场和马戏表演，同位置性价比最高，距离机场仅15分钟车程。
💰 费用参考（单人，不含秀票、购物、返程机票）：租车+油费 180元 + 住宿 335元 + 餐饮 200元 = 720元
🌇 11 月已入冬令时，日落约 16:45–17:00，长途段尽量排在白天
🎫 国家公园年票 America the Beautiful $80/车：约书亚树 + 大峡谷 + 锡安三园门票合计 $105，买年票回本
🌡️ 荒漠昼夜温差大：约书亚树夜里 5°C 上下，大峡谷清晨接近 0°C，羽绒和防晒都要带
